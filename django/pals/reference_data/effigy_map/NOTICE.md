# Effigy map assets

The map textures, marker catalog, and Lifmunk icon were imported from the open-source
[PalMap](https://github.com/voidpossum/PalMap) project under its GPL-3.0 project license.

The underlying Palworld map artwork and game icon belong to Pocketpair, Inc. and are used
here for a free fan tool. The coordinate transforms and marker catalog are retained for
read-only, approximate in-game guidance.
